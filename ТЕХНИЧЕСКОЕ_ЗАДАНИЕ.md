### 1.3 ProductionYouTubeGrabber - Защита от блокировок

**Проблема:** YouTube блокирует cookies через 10-15 минут

**Решение - многоуровневая защита:**

```python

    """
    Обход блокировок YouTube с помощью:

    4. Client Rotation (WEB/ANDROID/IOS)

    @rate_limit(min_delay=3.0, max_delay=5.0)

    def download_video(self, url: str) -> Dict:

        pass
```

**Компоненты:**

1. **ImprovedCookieManager**
   - Загрузка множественных cookie файлов из `cookies/youtube_cookies*.txt`
   - Health scoring (успехи/неудачи для каждого файла)
   - Автоматическая ротация при блокировке
   - Выбор наименее используемого cookie

2. **@rate_limit декоратор**
   - Минимальная задержка между запросами (3-5 сек)
   - Случайное jitter для имитации человека
   - Глобальный учет всех запросов

3. **@smart_retry декоратор**
   - Exponential backoff (2^attempt секунд)
   - Смена cookie при неудаче
   - Смена client (WEB → ANDROID → IOS)
   - Максимум 3 попытки с разными комбинациями

4. **Client Rotation**
   - WEB (по умолчанию)
   - ANDROID (при первой неудаче)
   - IOS (при второй неудаче)

**Автоматическое обнаружение:**

```python
# module1_download.py
cookies_dir = Path('cookies')

# Instagram
instagram_cookies = cookies_dir / 'instagram_cookies.txt'
if not instagram_cookies.exists():
    instagram_cookies = cookies_dir / 'instagram.txt'

# YouTube - множественные файлы
youtube_cookies_files = list(cookies_dir.glob('youtube_cookies*.txt'))
youtube_cookies_dir = cookies_dir if youtube_cookies_files else None

# Статус
print(f"Instagram: {'✅' if instagram_cookies.exists() else '❌'}")
print(f"YouTube: {len(youtube_cookies_files)} файлов (ротация)")
```

**Получение cookies:**

1. Установите расширение [Get cookies.txt LOCALLY](https://chrome.google.com/webstore/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)
2. Войдите в Instagram/YouTube
3. Экспортируйте cookies → сохраните в `cookies/`
4. Для YouTube можно создать 2-3 cookie файла с разных браузеров/профилей

### 2.2 Архитектура

```python
# module2_transcribe.py

def transcribe_video(video_path: Path, output_dir: Path):
    """
    Транскрибация видео через Whisper Small
    
    Параметры:
    - model: small (точность ~85-90%)
    - beam_size: 10
    - best_of: 5
    - initial_prompt: для контекста
    - language: ru/en (auto-detect)
    """
    model = whisper.load_model("small")
    result = model.transcribe(
        str(video_path),
        language="ru",
        beam_size=10,
        best_of=5,
        initial_prompt="Это видео на русском языке."
    )
    
    # Сохранение
    transcript_file = output_dir / "transcript.md"
    with open(transcript_file, 'w', encoding='utf-8') as f:
        f.write(f"# Транскрипция\n\n{result['text']}")
```

## 🔍 ИЗВЕСТНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: gallery-dl JSON формат
**Симптом:** Ошибка парсинга JSON от gallery-dl

**Причина:** gallery-dl возвращает JSON array: `[[2, {metadata}], [3, url, {metadata}], ...]`

**Решение:**
```python
data = json.loads(result.stdout)
for item in data:
    if isinstance(item, list) and len(item) >= 2:
        if isinstance(item[1], dict) and 'post_id' in item[1]:
            metadata_list.append(item[1])
```

### Проблема 2: gallery-dl не найден вне venv
**Симптом:** `FileNotFoundError: gallery-dl command not found`

**Причина:** Hardcoded 'gallery-dl' string, не в PATH

**Решение:**
```python
def get_gallery_dl_command() -> str:
    venv_binary = Path(__file__).parent.parent.parent / 'venv' / 'bin' / 'gallery-dl'
    if venv_binary.exists():
        return str(venv_binary)
    return 'gallery-dl'  # fallback
```

### Проблема 3: Dataclass missing fields
**Симптом:** `TypeError: InstagramPostResult.__init__() got unexpected keyword argument 'likes'`

**Причина:** Dataclass не содержал поля author, likes, comments_count, post_date

**Решение:**
```python
@dataclass
class InstagramPostResult(DownloadResult):
    author: str = ""
    likes: int = 0
    comments_count: int = 0
    post_date: Optional[str] = None
    hashtags: List[str] = field(default_factory=list)
    mentions: List[str] = field(default_factory=list)
```

### Проблема 4: YouTube блокировки
**Симптом:** Cookie перестает работать через 10-15 минут

**Решение:** ProductionYouTubeGrabber (см. раздел 1.3)
